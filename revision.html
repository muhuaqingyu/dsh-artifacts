4.20.7 本次修订：邀请类项目不显示「发送通知」（V3.5，7补.307）

  • 投标情况区右上角按钮为「导出 / 智慧预警 / 发送通知」；其中「发送通知」仅公开招标项目显示。
  • 邀请招标、议价采购项目的投标人来自系统内邀请 / 指定，不需要按供应商群发通知，发标管理页隐藏该按钮（导出、智慧预警不变）。
  • 商务标报价页、组建评标委员会等其它位置的「发送通知」不受影响；发送通知弹窗与短信发送记录功能保留。

5.6.7 本次修订：议价记录「查看」补齐新增字段、列表去掉附件列（V3.5，7补.305）

  • 「议价记录 · 查看」的发起记录完整展示新增议价记录时填写 / 选择的内容：议价轮次、发起时间、发起人、排名方式、报价类型、报价截止、参与议价投标人、报价须知，以及「是否抛价」「审批附件」「审批说明」。
  • 是否抛价单独一行；审批附件与审批说明各占一行，审批说明折行展示；汇总排名与分项排名两种视图都补齐这些字段。
  • 议价记录列表（开标 / 评标等处同一份列表）去掉「附件」列，只保留 序号 / 议价&流标 / 提交时间 / 状态 / 操作；审批附件改为在「查看」弹窗内查看，列表不再重复展示。

6.4.6 本次修订：物资类（分项单价排名）保留「评标设置」步骤（V3.5，7补.300）

  • 物资采购类商务标「去开标」进入开评标详情后，原口径因「分项单价排名」直接跳过「评标设置」步骤，导致评标办法无处设置；现与工程类一致保留该步骤。
  • 评标办法为「经评审的最低价法」「最高价法（分项单价由高到低）」二选一，默认经评审的最低价法；评标步骤为「报价评审」，保留设置排名优先级与底部评审流程条。
  • 工程设备类、综合服务类不受影响，仍为三选一（综合评估法 / 经评审的最低价法 / 有效最低价法）。

6.19.6 本次修订：议价记录列表去掉「附件」列（V3.5，7补.305）

  • 开评标系统「议价」步骤的议价记录列表与 5.6 为同一份列表：去掉「附件」列，只保留 序号 / 议价&流标 / 提交时间 / 状态 / 操作。
  • 新增记录的历史数据中已上传的审批附件不丢失，改为在「查看」弹窗的发起记录中查看（见 6.20）。

8.13.6 本次修订：是否使用CA决定是否出现「电子签章」步骤（V3.5，7补.299）

  • 项目计划「是否使用CA」选「是」时，步骤条在「评标办法索引」与「文件上传」之间出现「电子签章」步骤；技术标项目位于评标办法索引之后，商务标项目因无评标办法索引，位于开标一览表与文件上传之间。
  • 选「否」时不出现该步骤，「下一步」由评标办法索引（或开标一览表）直接跳到文件上传。
  • 电子签章页面仅展示投标文件预览（封面页：企业名称、项目名称、项目编号、标段、投标人、法定代表人、投标日期、盖章位），不提供签章、保存、上传等任何按钮，也不做完成状态校验，不影响文件上传与递交的既有校验。
